One error shape for every screen

The axios interceptor turns any failure into this object; components only read kind, message and fields. Field messages come straight from Laravel's errors[field][0].

{
  kind: "validation" | "auth" | "forbidden"
      | "not_found" | "server" | "network",
  message: "حصلت مشكلة عندنا…",   // shown to the customer
  fields: { phone: ["رقم الموبايل غير صحيح"] },  // 422 only
  status: 422                       // logged, never shown
}
